# Browser edition

Served on Static web hosting at /reversium/web/. No backend, subscription, sign-in, analytics or external runtime CDN is used. ZIP bytes are transferred to a module worker and inspected in Pyodide memory; input code is never executed. The worker disables network APIs before source inspection and is terminated when finished, cancelled or timed out. Results run in an opaque-origin sandbox with connect-src none. Clear removes page references; this is not secure memory erasure. Browser caches can retain application assets, not ZIPs saved by this app. Downloaded reports may contain private evidence. The hosting provider receives normal page/asset requests and IP connection information, never ZIP contents through this app.

32 MiB compressed input; analyzer limits remain 10,000 files, 256 MiB expanded, 4 MiB inspected per file, plus documented graph/token bounds. Five-minute stop. Desktop browsers recommended; large reports may exhaust device memory. No installation or runtime verification of input software; optional ChatGPT assistance requires the local application.

Build with `python scripts/build_browser.py`; it packages only reversium/*.py. Serve the repository through HTTP for local testing; file:// workers are unsupported. Runtime is pinned to Pyodide 314.0.7 (Python 3.14.2), distributed from its official jsDelivr distribution and self-hosted. MANIFEST.json records original hashes. PYODIDE-LICENSE contains the Pyodide license; PYTHON-LICENSE contains CPython terms. Reversium remains under the repository license.

Build 0.13.0 restores an optional AI handoff panel: choose a provider, explicitly select up to 20 findings, edit the exact request, and download it for manual submission. No automatic AI transmission, embedded provider chat or hosted OAuth connection is implemented. Provider websites open only on user action.

Build 0.21.0 allows a user-selected portable sandbox result JSON to be previewed and attached to an exact matching ZIP fingerprint. This does not execute software in the browser. The host brokers the result picker and bounded JSON/text downloads for its own report frame only. Test records remain local and separate from AI packets and static technical JSON.
